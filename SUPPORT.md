# Support

Use matching channel:

- [Documentation](https://bvolpato.github.io/ivygrep/) for installation and workflows
- [Discussions](https://github.com/bvolpato/ivygrep/discussions) for questions, ideas, and usage help
- [Issue forms](https://github.com/bvolpato/ivygrep/issues/new/choose) for reproducible bugs and concrete feature requests
- [Private vulnerability reporting](https://github.com/bvolpato/ivygrep/security/advisories/new) for security issues

For support requests, include `ig --version`, operating system, installation
method, exact command, and sanitized output. Never post credentials, private
source code, index contents, or model-host tokens.
