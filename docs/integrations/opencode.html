Give OpenCode local task context.

Add ivygrep as a local MCP server. The same index serves the CLI, the Web UI, and your agent.

Install

brew install bvolpato/tap/ivygrep

On Windows, install with winget install --id BrunoVolpato.ivygrep --exact. See all install options.

Add the server to opencode.json:

{
  "mcp": {
    "ig": {
      "type": "local",
      "command": ["ig", "--mcp"],
      "enabled": true
    }
  }
}

Use it

Use ivygrep to build one focused context pack before editing.

Keep the context small

  • Start with the wording of the task
  • Request output=context_pack
  • Set budget_tokens=8000
  • Use literal search only for identifiers you already know
