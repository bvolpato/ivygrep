One local server for every MCP client.

Connect an installed ig over stdio, or install the bundle from a client that supports the MCP Registry.

The server

ig --mcp

The registry bundle contains ivygrep binaries for macOS, Linux, and Windows. Registry metadata pins the SHA-256 of the bundle, and the release workflow publishes that metadata with GitHub OIDC.

The main request

tool: ig_search
query: fix refresh-token races
path: /absolute/repository/path
output: context_pack
since: main
budget_tokens: 8000

since resolves a Git ref and finds its merge base with HEAD. The pack includes commits on the current branch since that base, plus staged, unstaged, and untracked files. The ref itself is not the diff base. since is valid only for a context pack.

Tools

  • ig_search: search results or a context pack
  • ig_status: index state

Transport

  • stdio
  • Source, queries, embeddings, and indexes stay local
