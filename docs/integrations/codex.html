Codex integration

Give Codex focused code context.

Plugin installs ivygrep MCP configuration and a skill that starts coding tasks with one bounded context pack.

Install

Install ig, then add repository marketplace and plugin:

brew install bvolpato/tap/ivygrep
codex plugin marketplace add bvolpato/ivygrep
codex plugin add ivygrep@ivygrep

Windows: winget install --id BrunoVolpato.ivygrep --exact. See all install options.

Restart Codex after installation. Plugin invokes local ig --mcp; source and queries stay on machine.

Use

Use ivygrep to gather context for refresh-token race. Fix it and run auth tests.

Included

  • ig_search and ig_status MCP tools
  • use-ivygrep task-context skill
  • One 8,000-token context pack before broad exploration
