Bring repository context to Gemini CLI.

Connect one local stdio MCP server. ivygrep returns search results or context packs and does not upload your repository index.

Install

brew install bvolpato/tap/ivygrep
gemini mcp add --scope user --transport stdio ig ig --mcp

On Windows, install with winget install --id BrunoVolpato.ivygrep --exact. See all install options.

Restart Gemini CLI, then confirm that the server is listed:

gemini mcp list

Use it

Use ig_search to build one 8000-token context pack for this task, scoped to the current repository.

Useful inputs

  • output=context_pack
  • budget_tokens=8000
  • since=main to include commits on your branch since the merge base
  • The absolute path to the active worktree
