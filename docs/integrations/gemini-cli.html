Gemini CLI integration

Bring repository context to Gemini CLI.

Connect one local stdio MCP server. ivygrep returns search results or bounded context packs without uploading repository indexes.

Install

brew install bvolpato/tap/ivygrep
gemini mcp add --scope user --transport stdio ig ig --mcp

Confirm server after restarting Gemini CLI:

gemini mcp list

Use

Use ig_search to build one 8000-token context pack for this task, scoped to current repository.

Recommended inputs

  • output=context_pack
  • budget_tokens=8000
  • since=main when branch changes matter
  • Absolute path to active worktree
