Claude Code integration

Give Claude Code focused code context.

Plugin installs ivygrep MCP server and shared Agent Skill. One task pack connects branch changes, definitions, callers, dependents, and tests.

Install

Install ig, then add marketplace and plugin:

brew install bvolpato/tap/ivygrep
claude plugin marketplace add bvolpato/ivygrep
claude plugin install ivygrep@ivygrep

Windows: winget install --id BrunoVolpato.ivygrep --exact. See all install options.

Restart Claude Code after installation. Plugin invokes local ig --mcp.

Use

Use ivygrep context for refresh-token race. Fix it and run auth tests.

Included

  • ig_search and ig_status MCP tools
  • use-ivygrep Agent Skill
  • Local indexes shared across worktrees
