Give Claude Code the code behind the task.

ivygrep runs as a local MCP server. Claude Code can search your repository by meaning or by exact text, and can ask for one context pack before it edits.

Install

Install ig, then let it set up the client. The command keeps your existing configuration, checks the MCP handshake, and runs a search.

brew install bvolpato/tap/ivygrep
ig agent install claude

On Windows, install with winget install --id BrunoVolpato.ivygrep --exact. See all install options.

Restart Claude Code after setup.

Or install the plugin

The plugin adds the same MCP server and a skill that starts coding tasks with one context pack.

claude plugin marketplace add bvolpato/ivygrep
claude plugin install ivygrep@ivygrep

Manual MCP setup

claude mcp add -s user ig -- ig --mcp

Use it

Use ivygrep context for the refresh-token race. Fix it and run the auth tests.

What you get

  • The ig_search and ig_status tools
  • The use-ivygrep skill, with the plugin
  • One index that all worktrees share
