Search local code from Cursor.

One command updates the Cursor MCP configuration, keeps your existing servers, checks the handshake, and runs a search.

Install

brew install bvolpato/tap/ivygrep
ig agent install cursor
ig agent doctor

On Windows, install with winget install --id BrunoVolpato.ivygrep --exact. See all install options.

Restart Cursor after setup.

One project only

Add this to .cursor/mcp.json in the project:

{"mcpServers":{"ig":{"type":"stdio","command":"ig","args":["--mcp"]}}}

Use it

Use ig_search with output=context_pack and budget_tokens=8000 for this task.

A good request has

  • A concrete task or error as the query
  • The absolute repository path
  • since=main to include commits since the merge base, plus staged, unstaged, and untracked files
  • One literal search later, only if the task needs it
