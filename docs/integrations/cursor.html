Cursor integration

Search local code from Cursor.

Automatic setup updates Cursor MCP configuration, preserves existing servers, verifies handshake, and runs one smoke search.

Install

brew install bvolpato/tap/ivygrep
ig agent install cursor
ig agent doctor

Windows: winget install --id BrunoVolpato.ivygrep --exact. See all install options.

Restart Cursor after setup. For project-local configuration, add this to .cursor/mcp.json:

{"mcpServers":{"ig":{"type":"stdio","command":"ig","args":["--mcp"]}}}

Use

Use ig_search with output=context_pack and budget_tokens=8000 for this task.

Good task pack

  • Concrete task or error as query
  • Absolute repository path
  • since=main for active changes
  • One focused literal search only if needed
