One local command retrieves, connects, deduplicates, and budgets evidence for coding agents.

More useful than a list of search hits

ig context --since main combines task intent, branch diff, dirty worktree, and exact paths from pasted issues or stack traces. It then traverses dependencies, dependents, definitions, callers, references, tests, configuration, docs, and co-changes.

Capabilities

Local code search, indexed

BM25, vectors, AST chunks, browser UI, and MCP run on your machine.

Task-ready context packs

Turn task, issue, trace, diff, and dirty worktree into bounded graph evidence through CLI, MCP, or Web.

Fast indexed search

Warm daemon replay stays under 100 ms in current Linux validation. Hash results are available first; neural vectors build in the background.

🔒

Local by default

No hosted inference. No telemetry. Your source code, queries, and index data never leave your machine. Neural mode downloads model assets once on first use.

🧠

Intent queries

BM25 and local vector retrieval let prose queries find code without exact identifiers. Ask "where is the tax calculated?" and get the right function.

🌿

Branches, worktrees, and .gitignore are part of indexing. Branch switches use Merkle deltas instead of full rebuilds.

Built-in MCP server for Claude Code, Cursor, Codex, Gemini, and OpenCode. No separate plugin required.

🖥️

Web workspace browser

Run ig --web for local HTTP search across indexed projects, folder focus, daemon status, streaming results, syntax-highlighted files, and Markdown preview. Non-loopback listeners use a per-daemon access token.

🏗️

Code-aware chunks

24 Tree-sitter AST languages plus heuristic chunking for the rest of the 45 supported types.

New in v1.1.0

Daemon-backed web UI

Open a browser UI without leaving local mode. Search all tracked workspaces, drill into one folder, browse indexed files, and keep result and file panes independently scrollable.

Result cards show language icons, syntax-highlighted snippets, line markers, and selected-state highlighting. The file viewer highlights focused result lines and previews Markdown with a source toggle.

Loopback stays zero-config. A non-loopback bind prints an authenticated URL. On another device, replace only 127.0.0.1 with the server's LAN or Tailscale address and preserve the complete token=... query string. Open it directly and do not share it: the browser exchanges it for an HttpOnly session cookie, then removes it from the address. Restart the daemon to invalidate access.

Non-loopback serving uses plain HTTP: the token authenticates requests but does not encrypt source or results. Use a trusted network only, preferably Tailscale or an SSH tunnel. Never expose the port directly to the internet or untrusted Wi-Fi.

Architecture

Two-tier hybrid index

BM25 and literal search are available first; background jobs add hash and neural vectors.

1

Lexical index

File chunks go into SQLite and Tantivy first, so search works before vector jobs finish.

2

Hybrid fusion

BM25, literal matches, symbols, paths, and vector hits combine through Reciprocal Rank Fusion.

3

Local vectors

The daemon adds hash vectors and locally cached 256-dimensional static-retrieval-v1 vectors in the background. macOS releases use Accelerate-backed CPU math; the shell installer can select Apple Silicon Metal or Linux CUDA archives when available.

Git-aware indexing

Worktrees share one base index; branch switches re-index changed files only.

Worktree overlays

Each worktree references one shared base index. SQLite, lexical, and vector overlays store only divergent chunks and tombstones.

Branch-switch deltas

Merkle reconciliation re-indexes only changed files. Content hashes skip byte-identical files across branches.

Agent-safe defaults

Pass absolute repository or worktree path to ig_search. Use natural-language queries for concepts, literal=true for identifiers, or output=context_pack with since=main and budget_tokens=8000 for implementation.

The first search creates an index and starts incremental watching. Worktrees reuse one shared base index and store only divergent chunks and tombstones.

Install ivygrep

Automatic CUDA on NVIDIA Linux hosts with compute capability 8.0+. Automatic Metal on Apple Silicon. Run ig hardware for selected build and exact fixes.

$ brew install bvolpato/tap/ivygrep
