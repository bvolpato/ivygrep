Performance evidence

Benchmark reports, raw data, retained A/B runs, and validation commands for ivygrep performance work.

Reports

  • Benchmark dashboard - retained quality, latency, indexing, memory, footprint, and release metrics.
  • Daemon hot-query cache benchmark - warm daemon query p95 improved from 455.37 ms to 4.90 ms while preserving daemon/local result equivalence.
  • Linux kernel cold-index benchmark - fresh-index primary score improved by 10.62% on a 93,493-file Linux checkout.
  • Public code-retrieval benchmark - pinned CoIR quality, latency, indexing, memory, size, and variance evidence with raw machine-readable results.
  • Public challenge retrieval benchmark - six harder CoIR task families, 600 held-out queries, and non-default hash/hybrid/neural quality scores.
  • Public million-chunk benchmark - warm p95 53.77 ms -> 15.07 ms, indexing 4,963 -> 109,006 chunks/s, final index 1.06 GiB -> 0.46 GiB.
  • Portable embedding model bake-off - public quality, latency, memory, and model-selection evidence for the default neural profile.
  • Bounded learned reranker - held-out public quality, per-task regression, latency, model identity, and deterministic-fallback evidence.
