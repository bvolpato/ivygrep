# Evidence claim policy

The dashboard applies these definitions mechanically:

- **Portable:** The downloaded archives execute the documented offline procedure on all five supported targets, with baseline x86 ISA enforcement and no runtime toolchain or service dependency.
- **Competitive:** A controlled public comparison against a comparable local system is available for the same retrieval mode, corpus, hardware class, and resource budget.
- **State of the art:** A top-tier public quality result and a documented Pareto advantage in local latency, footprint, or portability are both present.

Current status:

- Portable: supported
- Competitive: not claimed
- State of the art: not claimed

Exact search is compared only with exact-search systems. Semantic retrieval is
compared only with local semantic systems under a comparable corpus, model
budget, hardware class, and resource budget. Missing comparisons remain
`unavailable`; they are not inferred from unrelated benchmark numbers.
