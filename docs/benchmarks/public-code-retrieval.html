Public Code Retrieval

Quality and speed from one reproducible runner

The BEIR/CoIR-style harness measures retrieval quality, indexing cost, index size, and cold versus warm query latency without requiring an external service.

nDCG@10graded ranking quality
MRR@10first relevant result
Recall@20relevant result coverage
p50 / p95cold and warm latency

Run the Offline Fixture

./build.sh
python3 scripts/eval_code_retrieval.py \
  --dataset tests/fixtures/retrieval \
  --binary target/release/ig \
  --mode hash

The checked-in multilingual fixture keeps CI deterministic. Modes cover lexical-only, hash, normal hybrid, and verified neural retrieval. Neural measurements wait for daemon model readiness; lexical-only results identify their local-process warm path.
